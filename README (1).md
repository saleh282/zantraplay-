# ZantraPlay 🎵

A sleek and modern **Music Player** built with pure HTML, CSS, and JavaScript. Features a Spotify-inspired UI with a song list, search functionality, and full playback controls.

---

## 🚀 Tech Stack

- **HTML5** — Structure & Audio API
- **CSS3** — Animations, Flexbox, Custom Properties
- **JavaScript (Vanilla)** — DOM manipulation & audio controls

---

## ✨ Features

- 🎧 **Music Playback** — Play, Pause, Stop, Forward, Backward
- 📋 **Song List** — Sidebar with all tracks
- 🔍 **Search** — Filter songs by title or artist in real time
- 🔊 **Volume Control** — Slider with mute toggle
- ⏱️ **Progress Bar** — Seek to any point in the track
- 🌊 **Animated Wave** — Visual indicator for the playing track
- 🖼️ **Album Art** — Floating animation while playing
